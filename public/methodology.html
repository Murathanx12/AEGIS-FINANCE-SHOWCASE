This is a curated engineering showcase, checked on 18 October 2026. It is separate from the operational application. Figures are dated observations, not a live feed.

What the paper figures measure

The sanitized snapshot was derived from local ROI and account-comparison receipts generated at 2026-10-17 23:51:19 UTC, with latest market marks on 16 October 2026. The public JSON file retains each selected account’s inception date, start and end paper NAV, own-window SPY return and benchmark-entry convention.

Return = (end NAV / start NAV − 1) × 100. Excess return is the account return minus the matching benchmark return, in percentage points. The graph displays endpoint returns; no intervening time series is implied. Accounts start on different dates and cannot be combined or compared as if they were one portfolio.

The whole cohort matters

Of 367 attempted accounts, 362 were priced and 307 had a compatible benchmark comparison: 20 ahead and 287 behind SPY. The ahead group includes 15 control twins and 5 strategy books. Excluding control twins, 5 of 80 were ahead. These accounts are correlated experiments, not 307 independent tests.

The five displayed examples were chosen after observing the results, including previously featured winners and losses. They are not a pre-registered portfolio, a recommended allocation or an exhaustive results table. Showing selected positive observations alone would hide the wider outcome.

What remains unproven

  • These are forward paper-account observations, not live-money returns, audited fund results or demonstrated investment skill.
  • Maximum drawdown is not supplied by these endpoint receipts. It remains unknown; it cannot be inferred from start and end NAV.
  • No independent cost-inclusive performance audit is established here. Account marking and benchmark-entry conventions differ and are retained in the JSON.
  • Internal evidence labels are project diagnostics. They do not constitute independent validation. The project’s policy requires 24 months of forward evidence before a skill claim.
  • Historical experiments and backtests are separate evidence classes. The showcase does not turn them into prospective proof.

Reproduce history with git rev-list --count HEAD, git log --reverse --format=%cs and git ls-tree -r --name-only HEAD. Detailed census exclusions and derivation instructions are in the repository’s evidence note.

Provenance and publication boundary

The public snapshot retains SHA-256 hashes of the private original receipts. Those hashes identify the source bytes but are not independent verification when the source is not available publicly. A reviewer can inspect the public arithmetic and methodology; independent re-audit would require authorized access to the originals.

The public repository contains curated aggregate results, newly authored diagrams and explanatory documents. It excludes holdings, account identifiers, credentials, private papers, personal correspondence and the full Optimus/chat corpus. The implementation is private. Public-source data rights remain separate from the software’s own intellectual property.

Reproduce the showcase

Clone the public repository and run python scripts/build.py. This validates snapshot arithmetic and local links, renders the results figure and stages only public/ into Vercel’s static build output. No broker, finance worker, browser session or model API is called.
