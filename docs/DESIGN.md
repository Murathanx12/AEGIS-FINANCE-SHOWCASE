# Showcase design

Audience: an engineering recruiter, collaborator or startup reviewer encountering Aegis for the first time. The page explains what is implemented, shows dated results, and makes the private/public boundary clear.

Palette: deep marine #10283c, ice #edf3f8, ink #102638, muted slate #4e6574, research blue #245bb0 and benchmark amber #9c5b19. Georgia supplies the editorial headline; system sans handles navigation, data and explanations. No font service is required.

Layout: left-aligned narrative beside a fixed research-loop drawing, followed by measured development scale, a four-stage interactive explanation, dated endpoint comparisons and a concise implementation brief. Mobile collapses to one column with an accessible data table. Motion is limited to user interaction; no moving physics graph or fake live stream.

The memorable object is the evidence record at the centre of the diagram. Charts use actual sanitized observations, explicitly identify selection after the fact, include losses and place the broader cohort denominator beside the selected examples. This is an engineering portfolio, not an investment product landing page.
