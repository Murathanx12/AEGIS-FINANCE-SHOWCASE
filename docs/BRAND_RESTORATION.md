# Restore the existing visual language

The original October7 design record and its working generators are authoritative. The October18 white/serif Aegis page and navy Optimus page departed from explicit recorded decisions. They are superseded by this restoration.

Use pure black; white structure; #4a8dff forward flow and #6fb0ff gains; #ff8a1f learning only. Use the original orbit front page and blackline explanatory diagrams, a light tracked sans wordmark, angular brackets and monospace labels. No invented decorative diagram, white result canvas or generic serif editorial treatment.

The original source generator is preserved as `scripts/brand_renderer.py` (MIT, adapted from the implementation's `scripts/render_public_assets.py`). The public wrapper renders only curated architectural SVGs and explicitly dated historical highlights. No finance service, worker, broker or model is invoked. The selected data is a historical portfolio showcase, not a current complete scoreboard.

References inspected: original Aegis motion skill, Optimus cross-project orbit/blackline skill, Aegis visual-language record, original orbit/pipeline/gauntlet SVGs, earlier Optimus neural-map generator, portfolio's own hard-surface artwork. Canva's Blueprint Effect design reinforces the user's grid/technical typography; the older February Aegis deck includes a white presentation cover, which does not supersede the later explicit dark-only website decision. Private Canva slides are references only and are not republished.
